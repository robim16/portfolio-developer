# **App Name**: DevSphere by Carlos

## Core Features:

- Exposición Interactiva de Proyectos: Muestra dinámicamente los proyectos del portafolio obtenidos de GitHub, destacando las tecnologías utilizadas (Laravel, Vue, Spring, Angular, Next, Django, .Net, Nestjs) y descripciones detalladas de cada uno. Incluye enlaces directos a los repositorios o demos en vivo.
- Asistente de Descripción de Proyectos con IA: Una herramienta que genera descripciones iniciales de proyectos e identifica tecnologías clave a partir de los metadatos del repositorio o un breve resumen proporcionado por Carlos, agilizando la creación de contenido para nuevas adiciones al portafolio.
- Resumen de Habilidades y Experiencia: Secciones dedicadas que detallan la experiencia profesional de Carlos Arteaga Jimenez (Cosmmotech, DyD Soluciones) y una representación visual de sus habilidades técnicas, incluyendo lenguajes de programación, frameworks (Laravel, Vue, Spring, Angular, Next, Django, .Net, Nestjs), bases de datos (PostgreSQL) y herramientas de IA (Cursor, Claude, Gemini, ChatGPT).
- Contacto y Llamada a la Acción: Un botón prominente de 'Contrátame' y un formulario de contacto que permite a posibles clientes o reclutadores comunicarse fácilmente. Incluye enlaces a redes sociales profesionales.
- Fondos Visuales Dinámicos: Formas geométricas animadas y gradientes de color similares al diseño de imagen proporcionado, adaptándose a las interacciones del usuario para crear una interfaz de usuario moderna y atractiva.

## Style Guidelines:

- Color primario: Oro Vibrante (#F2DB0F) para evocar energía y dinamismo, reflejando una personalidad de desarrollador creativo y moderno. (HSL: 50, 90%, 60%)
- Color de fondo: Un sutil crema desaturado (#FAFAEF), proporcionando una base suave pero luminosa que se alinea con un tema claro. (HSL: 50, 15%, 98%)
- Color de acento: Naranja Llama Dinámico (#E05B1A) para elementos interactivos y resaltados, complementando el color primario con un contraste cálido y audaz. (HSL: 20, 80%, 55%)
- Fuente para cuerpo y titulares: 'Inter', una sans-serif grotesca, ofreciendo una estética limpia, moderna y altamente legible adecuada tanto para títulos como para descripciones detalladas de proyectos en un portafolio de desarrollador.
- Utilizar iconos minimalistas de estilo de contorno para la navegación y las funciones, junto con iconos de marca específicos para tecnologías como Laravel, Vue, Spring, Angular, Next, Django, .Net, Nestjs, PostgreSQL y herramientas de IA, asegurando un reconocimiento claro y un aspecto profesional.
- Sección de héroe con un título grande y atractivo, un eslogan conciso y un botón de llamada a la acción prominente, como se muestra en la referencia de diseño. Emplear un diseño basado en cuadrícula para las secciones de proyectos y experiencia para mantener una estructura limpia, organizada y receptiva.
- Efectos de desplazamiento sutiles y suaves en los elementos interactivos y animaciones activadas por desplazamiento para que las secciones aparezcan, mejorando la participación del usuario sin distraer del contenido. Implementar una transición suave para los elementos de fondo dinámicos.
